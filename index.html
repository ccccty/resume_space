About

关于我

研究方向为光学与 SAR 卫星遥感影像的多源融合解译，以及太空计算场景下算力受限平台的实时推理。卫星遥感的问题条件与地面视觉不同：成像不受控，云雨、地形阴影与相干斑同时存在；标注样本稀缺且难以外推；而星上或在轨平台的功耗、算力与下行带宽都极为有限。应对方式是把解译流程拆成可独立验证的环节——模态一致化与配准、样本生成、融合网络、部署优化——每一环都用可量化的精度指标闭环。

在环天智慧（天府星座 /“环天星座”光学与 SAR 双模遥感卫星运营方）负责 L1、L2 级影像产品处理与多源融合分析，落地农田语义分割、地块级作物提取与地质、农业保险理赔的量化评估。现在航天八院主导点云、红外与可见光的多源融合算法重构，熟悉从模型训练、国产算力平台迁移到上线后质量维护的完整链路。

遥感仿真 · 开源 2026

RGB / SAR / LiDAR 多模态遥感仿真数据集生成器

面向遥感解译训练数据稀缺的多模态观测仿真器：给定三维模型与观测几何，离线生成可见光、红外（MWIR / LWIR）、毫米波雷达距离—多普勒、SAR 条带式（距离多普勒聚焦、相干斑与 NESZ）与激光雷达点云五类数据。所有模态共享同一三维世界与同一套天气状态，标注由三维包围盒统一投影导出，天然具备像素级跨模态配准，并可直接导出 YOLO 与 COCO 数据集。纯 Python 实现（numpy + Blender 无头渲染），不依赖 GPU 与网络，附参数化工作台与在线看板。
